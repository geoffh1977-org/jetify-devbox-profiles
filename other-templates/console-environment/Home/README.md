# Fake Home Directory Path

This is a starter Home path which works with the example profile.

The idea of the console-environment is to allow for multiple environments seperated on a single machine. this is achieved using docker and seperate mapped home directories. This is useful for running multiple environments at the same time for different purposes. A good use case is manageing multiple customers on a single machine. Each can have seperate credentials or ssh keys stored in their own Home environment path.
